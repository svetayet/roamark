# roaMark

Личная библиотека любимых GPX-треков: походы, покатушки, пробежки, лыжи.
Главное — в один тап **скачать исходный GPX**, чтобы открыть его в maps.me
или другом навигаторе прямо перед выходом.

## Что внутри

Три экрана:

- **Главная** — район (выпадающий список, основной помечен ⌂), карточки треков
  с мини-картой, активностью и километражем; «+» добавляет трек.
- **Трек** — большая карта с маршрутом, название, описание, километры
  и главная кнопка «Скачать GPX» (файл — байт в байт тот, что загружен).
- **Настройки** — тема (светлая/тёмная/системная), районы (создать,
  переименовать, назначить основной, удалить), выход.

Данные — в твоём собственном Supabase (бесплатный тариф): magic link вместо
пароля, приватный бакет для `.gpx`, доступ только у владельца. Хостинг —
GitHub Pages. Никаких чужих треков и никаких платежей за чужое хранение:
модель «свой Supabase у каждого» — каждый, кому даришь приложение,
разворачивает свой экземпляр по [docs/setup.md](docs/setup.md).

## Быстрый старт (демо)

```bash
npm install
npm run dev
```

Без настроенного Supabase приложение работает в демо-режиме: данные живут
в памяти вкладки (после перезагрузки — с нуля). Достаточно, чтобы посмотреть
интерфейс и потыкать карты.

Подключение настоящего хранилища и деплой — [docs/setup.md](docs/setup.md).

## Тесты и сборка

```bash
npx vitest run   # все тесты
npm run build    # проверка типов + production-сборка
```

## Как устроено

- Vite + React 19 + TypeScript (strict), тесты — Vitest + Testing Library.
- Карты — Leaflet: CyclOSM в светлой теме, CARTO dark в тёмной; атрибуция
  OpenStreetMap обязательна и всегда на месте.
- Данные — за одним интерфейсом `TrackRepository`: реализация в памяти
  (демо/тесты) и Supabase (`src/data/supabase/`); остальной код про Supabase
  не знает ничего.
- Палитра «ель» (тёмно-изумрудная), светлая и тёмная темы, PWA —
  ставится на телефон как приложение.
