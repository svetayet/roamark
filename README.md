# roaMark

Личная библиотека любимых GPX-треков: походы, покатушки, пробежки, лыжи.
Главное — в один тап **скачать исходный GPX**, чтобы открыть его в maps.me
или другом навигаторе прямо перед выходом.

## Что внутри

Три экрана:

- **Главная** — район (выпадающий список, основной помечен ★), карточки треков
  с мини-картой, активностью и километражем; «+» добавляет трек.
- **Трек** — большая карта с маршрутом, название, описание, километры
  и главная кнопка «Скачать GPX» (файл — байт в байт тот, что загружен).
- **Настройки** — тема (светлая/тёмная/системная) и районы (создать,
  переименовать, назначить основной, удалить).

Данные — локально в браузере (IndexedDB): без входа и паролей, открывается
мгновенно, работает без сети. Хостинг — GitHub Pages. Синхронизация между
устройствами — в разработке: Яндекс.Диск проверен и отклонён (Яндекс не
отдаёт файлы браузеру), проверяем GitHub.

## Быстрый старт

```bash
npm install
npm run dev
```

Настраивать ничего не нужно: данные живут в браузере.

## Тесты и сборка

```bash
npx vitest run   # все тесты
npm run build    # проверка типов + production-сборка
```

## Как устроено

- Vite + React 19 + TypeScript (strict), тесты — Vitest + Testing Library.
- Карты — Leaflet: CyclOSM в светлой теме, CARTO dark в тёмной; атрибуция
  OpenStreetMap обязательна и всегда на месте.
- Данные — за одним интерфейсом `TrackRepository`: локальная реализация
  на IndexedDB (`src/data/local/`), реализация в памяти — для тестов.
- Палитра «ель» (тёмно-изумрудная), светлая и тёмная темы, PWA —
  ставится на телефон как приложение.
