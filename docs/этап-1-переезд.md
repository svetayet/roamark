# Этап 1: переезд на локальное хранилище

Что изменилось: приложение больше не просит email и не ходит в Supabase.
Все треки и районы теперь хранятся в самом браузере (это называется IndexedDB) —
открывается мгновенно и работает без интернета. Синхронизация между
устройствами (сначала Яндекс.Диск, потом GitHub) — следующий этап.

## Что сделать тебе (один раз, ~5 минут)

1. **Открой сайт** на компьютере и на телефоне — сразу попадаешь в библиотеку,
   никаких экранов входа. При первом открытии появится район «Рядом».
2. **Перенеси районы руками**: в старом приложении у тебя было несколько
   районов (треков в них — ноль). Создай те же районы в «настройках»
   нового приложения и назначи основной, как было.
3. **Проверь**: добавь один трек, открой его, нажми «скачать GPX» —
   файл должен скачаться и открыться в навигаторе как раньше.
4. **Удали проект Supabase**: supabase.com → твой проект → Settings →
   General → Delete project. Делай это только после шагов 2–3 — когда
   убедилась, что новое приложение работает.
5. **Убери секреты из GitHub**: репозиторий → Settings → Secrets and
   variables → Actions → удали `SUPABASE_URL` и `SUPABASE_ANON_KEY`.
   Деплой их больше не читает, но хранить лишнее незачем.

## Важно знать

- Данные живут **в браузере устройства**: если почистить «данные сайта»
  в браузере — треки уйдут. Пока синхронизации нет, не чисти данные
  браузера и не удаляй приложение на телефоне, где лежат треки.
- Режим инкогнито забывает всё при закрытии окна.
- «Установить на главный экран» (PWA) работает как раньше.

## Проверка Яндекса для синхронизации (spike)

Этап 2 — синхронизация с Яндекс.Диском одной кнопкой («чей новее, тот
и главнее»). Но сначала нужно проверить, что браузеру Диск всё отдаёт:
на сайте есть временная страница `#/spike` — она прогонит всю цепочку
(создать папку → залить файл → скачать его обратно → сверить байты)
и скажет прямо: подходит Яндекс или нет.

Как получить токен для проверки — см. раздел «Токен Яндекса» внизу
этого файла.

## Токен Яндекса (для страницы #/spike)

Один раз регистрируем «приложение» Яндекса — это просто разрешение
для roaMark трогать одну папку на твоём Диске:

1. Зайди на [oauth.yandex.ru](https://oauth.yandex.ru) под своим
   Яндекс-аккаунтом → «Зарегистрировать приложение».
2. Название: `roaMark`. Платформа: **веб-сервисы**.
   Redirect URI: `https://svetayet.github.io/roamark/`
3. Доступы: отметь «Яндекс.Диск REST API» → «Запись в любом месте на Диске»
   и «Чтение всего Диска».
4. Сохранить → скопируй **ClientID** (строка вида `a1b2c3...`).
5. Открой в браузере ссылку, подставив свой ClientID вместо `CLIENT_ID`:

   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=CLIENT_ID&redirect_uri=https%3A%2F%2Fsvetayet.github.io%2Froamark%2F&scope=cloud_api:disk.read%20cloud_api:disk.write
   ```

6. Нажми «Разрешить» — Яндекс вернёт тебя на сайт roaMark. Токен подхватится
   автоматически: сразу открой `#/spike` — он уже будет в поле. Нажми
   «проверить» — страница сама скажет, подходит Яндекс или нет.
7. Не перезагружай страницу между согласием и `#/spike`: токен живёт
   до первой перезагрузки. Если всё же перезагрузила — просто открой
   ссылку из шага 5 ещё раз.

Если Яндекс не даст токен таким способом или проверка завалит какой-то
шаг — напиши мне, какой именно: найдём другой путь (второй кандидат —
GitHub).
