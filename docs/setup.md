# Настройка roaMark — инструкция для владелицы

Всё делается один раз, руками, в браузере. Приложение уже умеет работать без Supabase
(демо-режим), но чтобы треки сохранялись по-настоящему — пройди эти шаги.
Ориентировочно 20–30 минут.

## 1. Supabase — хранилище

1. Зайди на [supabase.com](https://supabase.com), создай аккаунт (бесплатного тарифа хватает).
2. **New project**: имя любое (например `roamark`), регион любой (ближний — Франкфурт),
   пароль базы придумай и сохрани — он больше не пригодится в этом приложении.
3. Подожди, пока проект соберётся (1–2 минуты).
4. Открой **SQL Editor** (иконка в левой панели) → **New query**.
5. Открой из этого репозитория файл `supabase/migrations/0001_init.sql`,
   скопируй **весь** текст, вставь в редактор → **Run**.
   Должно пройти без ошибок: появятся таблицы `districts` и `tracks`, политики и бакет `gpx`.
6. Проверь себя по чеклисту `docs/sql-review-checklist.md` (раздел «Совместимость с приложением»).
7. **Authentication → Providers → Email**: должен быть включён (обычно включён по умолчанию).
   Галочка Confirm email не критична — magic link работает и так.
8. Скопируй ключи: **Settings → API** (Project settings → API Keys):
   - **Project URL** — что-то вроде `https://abcdefgh.supabase.co`
   - **anon public key** — длинная строка (это НЕ service_role — его не трогаем вообще).

## 2. GitHub — код и деплой

1. Залей этот репозиторий к себе на GitHub (свой аккаунт, репозиторий можно приватный).
2. **Settings → Secrets and variables → Actions → New repository secret** — добавь два:
   - `SUPABASE_URL` = Project URL из шага 1.8 (без `/rest/v1/`!)
   - `SUPABASE_ANON_KEY` = anon public key
3. **Settings → Pages**: в **Source** выбери **GitHub Actions** (не «Deploy from a branch»).
4. Ничего больше настраивать не нужно: деплой сам подкладывает секреты в сборку
   (`.github/workflows/deploy.yml`, шаг «Env for the app») — Vite читает их из `.env.production`,
   который в git не попадает.
5. Запушь что-нибудь в `main` (или Actions → deploy → Run workflow) и подожди зелёную
   галочку → открой адрес Pages (Settings → Pages покажет URL).

## 3. Первый вход — важный момент

**Первый, кто войдёт по magic link, становится владелицей — регистрация для всех
остальных закрыта навсегда** (так задумано: «свой Supabase у каждого»).

Поэтому:

1. Сразу после деплоя открой сайт **сам(а)**.
2. Введи свою почту → «войти» → открой письмо → перейди по ссылке.
3. Убедись, что ты внутри (видишь пустой список и район «Рядом»).
4. Только теперь можно делиться ссылкой: другой человек увидит приложение,
   но войти не сможет (ему нужен свой Supabase — та же инструкция).

## 4. Проверка после настройки

Пройдись по списку (каждый пункт — минута):

- [ ] Добавить трек: выбрать `.gpx`-файл → под полем появилась «✓ … км», сохранить.
- [ ] Открыть трек → **«Скачать GPX»** → скачанный файл совпадает с исходным
      (размер/имя; при сомнении — открыть в текстовом редакторе и сравнить).
- [ ] Настройки → сменить тему (светлая/тёмная/системная) — весь интерфейс и карта меняются.
- [ ] Настройки → создать район, переименовать, назначить основным (⌂ переехал).
- [ ] Удалить трек → подтверждение → трека нет ни в списке, ни в Supabase Storage.
- [ ] Телефон: открыть сайт, «Добавить на главный экран» — ставится как приложение.

## 5. Если приложение «уснуло»

Бесплатный Supabase засыпает после ~7 дней без запросов. Еженедельный keep-alive
(GitHub Actions) обычно спасает, но если сайт вдруг показывает пусто и не входит:

1. supabase.com → твой проект → баннер «Project paused» → **Restore**.
2. Подожди пару минут — данные на месте, ничего не теряется.
3. Если проект стоял больше 90 дней — сначала проверь, не удалили ли его совсем
   (тогда из бэкапа не восстановить; храни копии любимых треков в облаке).

## Если что-то пошло не так

- Ошибка при Run SQL — скорее всего вставился не весь текст; повтори с одним куском.
- Сайт открылся, но «Нужно войти» по кругу — проверь, что `SUPABASE_URL` без слеша
  и без `/rest/v1`, а ключ именно anon.
- Скачивание не работает — бакет `gpx` не создался; прогони SQL из миграции ещё раз
  (повторный запуск безопасен только для куска про бакет — таблицы лучше не дублировать).
