Приложение для хранения моих любимых треков покатушек и походиков выходного дня.
Название будет roaMark обыгрывающее слова roam и mark. 

Я загружать буду вручную трек через кнопку "добавить трек".

Все треки хранятся в формате gpx.

для трека вводится:
- категория (пеший, вело, бег, лыжи)
- район (редактируемый список районов нужен с одним уже созданным по умолчанию с названием "Рядом" - редактируемым. в списке районов один можно выбрать основной - у него должен быть значок - домик, именно его треки будут показываться на главной странице)
- короткое название (до 200 символов)
- описание опциональное (до 1000 символов)
всё это можно поменять можно потом.

трек можно удалить.

на главной странице показывать вверху кнопку "+" для добавления трека

потом должен показываться список треков из основного района.
для каждого трека в списке:
 - миниатюрка трека на карте, название, иконка для вида активности (пеший, вело, бег, лыжи) и километраж

вверху также должен быть выпадающий список других районов, при его выборе показываются треки оттуда. Если там пусто - показывается "ничего нет" и предложение добавить трек.
